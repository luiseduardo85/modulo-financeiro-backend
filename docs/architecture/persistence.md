# Persistence

Banco: PostgreSQL.
Schema: Flyway.
Hibernate em produção: `ddl-auto=validate`.

## Naming
Tabelas, colunas, constraints e índices usam camelCase.
Exemplos: `"contaFinanceira"`, `"empresaId"`, `"dataVencimento"`.
Não usar snake_case.
Quoted identifiers são necessários quando houver maiúsculas a preservar.

## Types
ID: BIGINT GENERATED BY DEFAULT AS IDENTITY / Java Long.
Money: NUMERIC(19,2) / BigDecimal.
Business date: DATE / LocalDate.
Audit/event timestamp: TIMESTAMPTZ / preferencialmente Instant.
Boolean: BOOLEAN.
Enums: VARCHAR + EnumType.STRING.

## Rules
- Flyway é fonte de verdade do schema.
- Evitar cascade delete em dados financeiros.
- Rascunho pode ser excluído quando permitido.
- Consultas company-scoped incluem empresa.
- Optimistic locking nas operações documentadas.
