# Backend Architecture

## Domain
Aggregates, Entities, Value Objects, Domain Services, Domain Events, Repository Ports, Domain Exceptions.

## Application
Use Cases, Commands, Queries, Results, autorização e fronteiras transacionais.

## Infrastructure
JPA/Hibernate, PostgreSQL, repository adapters, Flyway, Outbox/mensageria, integrações e configuração.

## Interfaces
REST Controllers, Request/Response DTOs, Exception Handlers.

Controllers não possuem regras de negócio.
