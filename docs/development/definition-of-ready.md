# Definition of Ready

Uma Issue funcional só pode entrar em desenvolvimento quando possuir:

- [ ] objetivo claro;
- [ ] Use Case identificado;
- [ ] documentação do Use Case disponível;
- [ ] regras de negócio relacionadas identificadas;
- [ ] permissões necessárias identificadas;
- [ ] critérios de aceite definidos;
- [ ] dependências conhecidas;
- [ ] escopo incluído definido;
- [ ] fora do escopo definido;
- [ ] decisões arquiteturais relevantes identificadas;
- [ ] nenhuma decisão obrigatória de negócio pendente.

## Regra para Copilot

Se a Issue não estiver Ready, o Agent não deve implementar comportamento indefinido.

Use Plan para identificar lacunas antes da implementação.
