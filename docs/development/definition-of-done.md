# Definition of Done

Uma Issue só é considerada concluída quando:

- [ ] implementação concluída dentro do escopo;
- [ ] regras de negócio documentadas respeitadas;
- [ ] arquitetura respeitada;
- [ ] testes unitários relevantes passando;
- [ ] testes de aplicação relevantes passando;
- [ ] testes de integração passando quando houver persistência;
- [ ] migrations Flyway validadas quando aplicável;
- [ ] contrato da API validado quando aplicável;
- [ ] isolamento multiempresa validado;
- [ ] concorrência analisada quando aplicável;
- [ ] documentação atualizada;
- [ ] build passando;
- [ ] nenhuma decisão pendente ocultada;
- [ ] nenhuma feature futura implementada por conveniência;
- [ ] Pull Request revisado.

Cobertura numérica isolada não substitui testes comportamentais.
